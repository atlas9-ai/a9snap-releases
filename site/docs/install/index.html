    Install A9 Snap

    Two ways to get A9 Snap on Windows 10 or 11. They give you the same app.

    Last updated for A9 Snap 0.13.6

    From the Microsoft Store#

    This is the way we recommend. Windows installs A9 Snap for you and keeps it up to date.

    Click the badge, then click Get (or Install) on the Store page. Open A9 Snap once after it installs. Getting started shows what you see.

    Download the installer#

    If you can't or would rather not use the Microsoft Store, install A9 Snap with the installer from this page.

    Download the installer

    The button saves the newest A9Snap-Setup-x64.exe. Then:

    1. Open the file.
    2. If Windows shows Windows protected your PC, click More info, then Run anyway.
    3. Follow the installer. It installs for your Windows user only and does not ask for administrator rights.
    4. A9 Snap starts by itself when the installer finishes. The first time, it opens the Home window so you can see it is running.

    Windows shows that warning because early builds are not signed with a Windows certificate yet. Windows warns about any program it has not seen many times. It is not a finding about A9 Snap. There is no account, and A9 Snap sends nothing beyond its update check (and Pro's license check, if you buy Pro). See Privacy.

    The installer version checks for updates by itself. You can pick the update channel in Updates and about. See Updates and channels.

    Which one should I pick?#

    It is the same app either way, so pick the one that suits you.

    • The Microsoft Store version updates through the Store and skips the Windows warning.
    • The installer version updates itself and lets you pick the update channel.
    • Already installed A9 Snap from a9snap.com? Keep using it. The Store version is a separate install with its own settings.
