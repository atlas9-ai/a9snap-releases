    Where screenshots go

    Pictures are saved as numbered PNG files in one folder, and the numbering picks up where the folder left off.

    Last updated for A9 Snap 0.3.4

    Every capture is saved to your screenshots folder as a PNG, as well as going to the clipboard. This page covers the folder, the file names and the clipboard option. All of it lives in Saving on the Home window.

    A secure capture (Pro) is the exception: it goes to a folder of its own and is never in this one.

    Choose the folder#

    By default A9 Snap saves to Screenshots on your Desktop (%USERPROFILE%\Desktop\Screenshots). The folder is made when the first picture is saved.

    1. Open the Home window and choose Saving.
    2. Next to Screenshots folder, click Browse… and pick a folder.
    3. Click Open any time to see the folder in Explorer.

    To go back, click Use the default folder. The same Folder button is on the Home window's left side, and Open screenshots folder is in the tray menu.

    File names and numbering#

    New files are named snag_0042.png: a prefix, a number and .png. The first picture in an empty folder is snag_0001.png.

    • A9 Snap reads the folder on every capture. The new number is the highest one it finds, plus one.
    • It never fills gaps and never overwrites a file. If you delete snag_0007.png, the next capture is still the highest number plus one. When you delete the newest capture from A9 Snap (the trash can or Delete), its number also stays taken until A9 Snap restarts, so the next capture doesn't reuse it.
    • It counts only files named like your prefix, with the number after it and .png at the end. It ignores letter case, and treats -, _, a space or nothing between the prefix and the number as the same. With the prefix snag_, it counts snag_0042.png, SNAG-7094.png and Snag 12.png. It does not count IMG_0042.png or notes.png.
    • If the folder already has such a sequence, the next file copies the style of the highest-numbered one: the same letter case, the same separator and the same number of digits. A folder whose newest file is SNAG-7094.png gets SNAG-7095.png next, whatever the prefix in Settings says.

    The File name row has two boxes. Prefix is the text before the number (the default is snag_). Digits is how many digits the number is padded to with zeros, from 0 to 6, and 0 means no padding. They are used while the folder has no numbered files yet; after that the folder's own style wins. A line under File name shows Next file with the real name, read from your folder as you change things.

    A prefix can't be empty and can't contain \ / : * ? " < > |.

    Also copy as file#

    Most apps paste a picture straight from the clipboard. A few want an attachment instead, such as some chat and email apps. Turn on Also copy as file and the saved file goes on the clipboard too, next to the picture. Apps take whichever they understand. It is off by default.

    When something can't be saved#

    If the folder is not writable or the disk is full, you still get the picture on your clipboard. The note says Copied · not saved and gives the reason, and it stays for five seconds even if you turned confirmations off. Pick a different folder in Saving.
