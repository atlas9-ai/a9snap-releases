    Start at login

    A9 Snap can start by itself when you sign in to Windows, so your hotkey is always ready. Here is how it behaves, and what to do when Windows says no.

    Last updated for A9 Snap 0.5.2

    Start at login is on for a new install, in the downloaded version and the Microsoft Store version alike. A9 Snap starts straight into the tray: no window opens and nothing asks you anything. If you had turned it off before, it stays off.

    The Microsoft Store version#

    The Microsoft Store version starts at login through Windows' own startup task instead of a startup entry, because a Store app's startup entry would never reach Windows. It is on for a new install, the same as the downloaded version, but the Store doesn't launch the app for you: open A9 Snap once after installing, and that first launch switches the startup task on. Settings › Apps › Startup in Windows then shows A9 Snap with its switch on.

    The Start at login switch turns the task on and off. If you turn it off in Windows, A9 Snap says so and Fix in Windows opens that page, exactly as below; if an administrator's policy turned it off, the same line shows, and A9 Snap never tries to override either. A login start is quiet, as with the downloaded version: no window, only the tray icon.

    The restart recovery described at the bottom of this page works the same way in the Store version: the one-time task starts A9 Snap through its app execution alias (a9snap.exe in your WindowsApps folder), because Task Scheduler can't start a Store app by the path of its program file.

    Turn it on or off#

    1. Open the Home window and choose Shortcuts.
    2. Use the Start at login switch.

    Turning it on adds a startup entry for your Windows user, with the program's path in quotes (the install folder has a space in it). Turning it off removes the entry.

    What the switch shows#

    The switch shows what Windows will really do, not only what you saved. Windows has its own list in Settings › Apps › Startup, and it can turn A9 Snap off there.

    • If Windows turned it off, the switch stays on and a line under it says Windows has turned this off in Startup apps. Click Fix in Windows. It opens that Windows page. Turn A9 Snap on there. A9 Snap never switches Windows' own setting back on for you.
    • If A9 Snap could not add its startup entry, the line says A9 Snap couldn't add itself to Windows startup.

    It checks itself#

    A9 Snap checks its startup entry every time it starts. If the entry is missing, has no quotes, points at another copy (an old path or a development build) or is out of date after an update, A9 Snap puts it right. If you switch the setting off, the entry is removed.

    After Windows closes your apps for an update#

    Sometimes Windows closes every app so it can restart for an update, and then the restart never finishes, or you cancel it. Nothing signs you in again, so the startup entry never fires and A9 Snap would stay closed.

    To cover that, when Windows ends your session and Start at login is on, A9 Snap sets a one-time task in your own Task Scheduler named A9 Snap relaunch after Windows closed it. It starts A9 Snap again two minutes later and ends after an hour.

    • If the PC really restarts, the startup entry starts A9 Snap and removes the task.
    • Every start of A9 Snap removes the task.
    • A9 Snap never holds up a shutdown or a restart, and it asks Windows to start it again after a crash.
    • With Start at login off, no task is made.

    Checking what happened#

    The log file records how each run ended: quit from the tray, Windows ending the session (and whether the session is really ending), a crash, or a normal exit. A login start is recorded as started at login.
