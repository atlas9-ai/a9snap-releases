    Updates and channels

    How A9 Snap finds and installs new versions, and what the Dev and Stable channels mean.

    Last updated for A9 Snap 0.3.6

    A9 Snap updates itself, but never without you. It checks, downloads in the background, and then waits for you to restart.

    The Microsoft Store version#

    If you installed A9 Snap from the Microsoft Store, Windows updates it and A9 Snap does not check for updates itself. There is no Check for updates button, no Update now card, no channel and no update item in the tray menu. Updates and about says Updates come from the Microsoft Store., and the version line shows your version with Microsoft Store, for example v0.3.6 · Microsoft Store. To look now, open the Microsoft Store, then Library and Get updates. Everything below is about the version you install from a9snap.com.

    How an update works#

    1. A9 Snap checks on launch and every few hours. You can check now with Check for updates in Updates and about, or in the tray menu.
    2. If a newer version exists, it downloads it and checks its signature. The Home window shows a card: Downloading 0.3.3…, then Version 0.3.3 is ready. The tray menu says Restart to update to 0.3.3.
    3. Click Update now on the card, or choose the tray item. A9 Snap restarts. It takes a few seconds, and your settings and screenshots are untouched.

    If you ignore the card, nothing happens. The update waits until you are ready. A failed check never throws away an update that is already downloaded.

    Dev and Stable#

    The channel decides which versions you are offered.

    • Dev gets every build. It is the default, and it is how new features reach you first.
    • Stable gets only the builds that were promoted after they had time to prove themselves.

    To switch, open Updates and about and pick the other one in Update channel. The version line at the bottom left of the Home window shows your channel, for example v0.3.3 · Dev. Switching to Stable never installs an older version. It just waits for the next promoted build.

    See what changed#

    Release notes in Updates and about opens your version's notes on GitHub. What's new lists every version in this manual.
