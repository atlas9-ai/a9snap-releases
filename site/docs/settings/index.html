    Manual · Settings

    Settings sections

    Every setting, section by section, in the order the Home window lists them, with what each one does and its default.

    Last updated for A9 Snap 0.9.0

    Every setting is in the Home window's menu of sections. Each section has a ? button at the top right that opens its manual page. A change is saved the moment you make it, and A9 Snap checks it. If a value is not allowed, a line under the setting says why and the setting goes back to what it was. For the window itself, see The Home window.

    Shortcuts#

    • Capture hotkey starts a screenshot. Default Alt+Z.
    • OCR capture hotkey copies recognized text from a region without saving a picture. Default Alt+X.
    • Recent captures hotkey opens the strip. Default Alt+Shift+Z.
    • Secure capture is shown, not set: the capture hotkey, then S in the picker (a Pro feature with a Pro badge; without Pro, pressing it opens the Pro sheet). Under the hotkeys a line lists the picker's keys: click a window, drag a region, F full screen, S secure (Pro), Esc cancel.
    • Start at login starts A9 Snap in the tray when you sign in to Windows. On by default for a new install. See Start at login.

    To change a hotkey:

    1. Click the box. It says Press the keys…
    2. Press the combination you want, for example Ctrl+Alt+P.
    3. If the key is allowed and free, it is saved. Press Esc to leave the box without changing it.

    A hotkey needs Ctrl, Alt, Shift or Win with a key. Function keys and PrintScreen may stand alone. The three hotkeys must all be different. A9 Snap never takes Ctrl+Alt+S, Win+Shift+S or Ctrl+C, V, X and Z. They belong to Windows and to every app's editing keys.

    If another app already owns a key, the box is marked and a line says Alt+Z is taken by another app. Pick another. The tray icon also shows a warning badge until you fix it.

    Saving#

    • Screenshots folder is where pictures are saved. Default Desktop\Screenshots. Browse… picks another, Open shows it, Use the default folder goes back.
    • File name has Prefix (default snag_) and Digits (default 4, from 0 to 6). A line shows Next file.
    • Search inside screenshots (Pro) reads the words in each capture on this PC so the strip can find a capture by what is in it. On by default with Pro; without Pro the row shows a Pro badge and opens the Pro sheet. A line under it says how far the reading is (Read 412 of 1,280 captures, then All captures read), and Clear text index deletes the words read so far, after asking. The index holds text from your screenshots, in the hidden .a9snap folder in your screenshots folder, and never leaves this PC. Turning the setting off stops reading and deletes the index. Secure captures are never read. See Privacy.
    • Redact every capture before it's copied (Pro) blurs email addresses, phone numbers and card numbers in each new capture before it reaches the clipboard and your screenshots folder. Off by default; without Pro the row shows a Pro badge and is greyed out. It adds a moment before the picture is on the clipboard (about a second for a full screen of text). The untouched original is kept in the hidden .a9snap folder, so Revert in the editor brings it back, and Clear on Edit originals removes it. Secure captures are never redacted. See Auto-redact.
    • What auto-redact blurs (Pro) lists the kinds: Email addresses, Phone numbers and Card numbers are on; IP addresses and Long key-like strings are off. The choice is used by this setting, Redact in the editor and Copy redacted in the strip.
    • Remember which app each capture came from notes the app and window title of each new capture so the strip can search by them. On by default. Window titles can contain an email subject or a document's name; they stay in the hidden .a9snap folder in your screenshots folder and never leave this PC. Turning it off stops new notes and keeps the old ones; Clear next to it deletes them. See Privacy.
    • Edit originals says how many untouched originals the editor has kept so Revert works and how much room they take (23 files, 41 MB). They still hold anything you blurred. Clear asks first, then sends them to the Recycle Bin. After that Revert is gone for those captures; the edited pictures stay as they are and keep their Volt dot.
    • Also copy as file puts the saved file on the clipboard next to the picture. Off by default.

    Where screenshots go explains the numbering in full.

    Strip and editor#

    • Captures in the strip is how many of the newest captures the strip shows: 6, 9, 12, 18 or 24. Default 12. A search finds all of them, however many.
    • Per row is how many of them sit in one row: 4, 6, 8 or 12. Default 6, so 12 captures make two rows of six. A narrow screen gets fewer to a row, and a short one scrolls.
    • Drop shadow in the editor starts each picture in the editor with the shadow on: a soft shadow and a see-through margin around the saved picture. Off by default; the editor's Shadow button switches it per picture.
    • Open the editor after every capture opens the editor on each capture as you take it. Off by default. When it is off, press E in the strip or click Edit on the note.

    Notifications#

    • Show a confirmation shows a small note at the bottom right after each capture, such as Copied · snag_0042.png. On by default.

    The note stays about a second and a half, or three and a half seconds when it has an Edit button. Problems always show, and stay for five seconds, whatever this setting says.

    Updates and about#

    • Version shows the number you have, your channel and when the last check got an answer. Check for updates looks now. When an update is ready the button becomes Update now.
    • Update channel is Dev or Stable. See Updates and channels.
    • What's new shows the newest change in a sentence. Release notes opens this version's notes on GitHub. All versions are in What's new.

    In the Microsoft Store version there is no Check for updates button and no Update channel: the row says Updates come from the Microsoft Store. At the bottom, a line reminds you that nothing leaves your PC except the update check. See Privacy.
