    Privacy

    Nothing leaves your PC except the update check. No account, no telemetry, no uploads.

    Last updated for A9 Snap 0.3.5

    A9 Snap is built to stay on your computer. This page lists everything it stores and everything it sends.

    What leaves your PC#

    Only the update check. See The update check. A9 Snap has no account, no sign-in, no analytics and no crash reporting. It never uploads a screenshot anywhere.

    The update check#

    On launch and every few hours, A9 Snap asks one public file whether a newer version exists. The file is channels/dev.json or channels/stable.json, depending on your channel, at raw.githubusercontent.com in the A9 Snap releases repository on GitHub. If there is a newer version, A9 Snap downloads the installer from that same repository's releases and checks its signature before it will install anything.

    Those requests carry the normal information any web request does, such as your IP address. They carry no screenshot, no file name and no setting.

    What is stored on your PC#

    • Screenshots go to the clipboard and to your screenshots folder, and nowhere else. Thumbnails for the strip and the Home window are made in memory and never written to disk.
    • OCR uses Windows' built-in recognizer on your PC. The picture goes to it in memory only, and the recognized text goes only to the clipboard when you ask for it. An OCR capture saves no PNG. There are no temporary image or text files and no recognized text in the log.
    • Originals of edited captures are kept in a hidden .a9snap folder inside your screenshots folder. After a blur, the saved file has the pixels destroyed but the original still holds them. See Blur is permanent in the saved file. Delete .a9snap before you share the whole folder.
    • Settings are in settings.json in %APPDATA%\ai.atlas9.a9snap.
    • The log is in the logs folder beside it. It records sizes, timings and status codes, never the content of a screenshot, a file or recognized text.
    • Start at login adds one startup entry for your Windows user, and a one-time Task Scheduler task when Windows ends your session. See Start at login.

    This website#

    The manual loads its own fonts and scripts from a9snap.com. It has no analytics and no cookies. The home page loads its fonts from Google Fonts and reads the newest version number from the same GitHub file that the app uses.
