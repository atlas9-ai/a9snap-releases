    Saving, Save as new and Revert

    Save over the capture, save as a new numbered file, or go back to the original. Here is exactly what each one does to your files.

    Last updated for A9 Snap 0.3.2

    When you finish drawing, you have two ways to save and one way back. This page explains each, and what happens to the untouched original.

    Save over the capture#

    Press Ctrl+S or click Done.

    1. A9 Snap keeps the untouched original first, if it has not already (see Where originals are kept).
    2. It writes your edit over the same file, under the same name. The numbering never changes.
    3. It puts the result on the clipboard, as the picture and as the file, just like a capture.
    4. A note says Saved · snag_0042.png · copied, and the editor closes.

    If you did not change anything, Done just closes the editor and writes nothing.

    Save as new#

    Press Ctrl+Shift+S or click Save as new. The edit is saved as the next numbered file, the highest number plus one, in the folder's own style. The original capture is left exactly as it was. The result goes on the clipboard and the note says Saved as · snag_0043.png · copied.

    Use this when you want to keep both the plain screenshot and the marked-up one.

    Close without saving#

    Press Esc. If you have changes that are not saved, the editor asks inside its own window: Save your changes? with three buttons.

    • Save saves over the capture, like Done. Enter chooses it.
    • Discard closes and keeps the file as it was.
    • Cancel goes back to editing. Esc chooses it.

    Esc works from the inside out: it first leaves a text you are typing, then a drag, then a crop waiting for Enter, and only then asks about closing.

    Revert#

    Revert puts the original picture back. It shows in the top bar only when the capture has an original to go back to, which means you have saved an edit over it at least once.

    1. Open the edited capture in the editor.
    2. Click Revert.
    3. Read Go back to the original? It says the file is replaced by the picture as it was captured and that your edits to it are lost.
    4. Click Revert to confirm, or Cancel.

    A note says Reverted · snag_0042.png. The original is removed from its hidden folder once it is back, so a second Revert has nothing to go back to until you save another edit.

    Where originals are kept#

    The first time you save an edit over a capture, A9 Snap copies the untouched picture into a hidden folder named .a9snap inside your screenshots folder. The copy is named like snag_0042.orig.png. A second edit keeps the first original, never an earlier edit.

    • The numbering ignores that folder, so editing changes no number.
    • The strip and the Home window show an edited capture with a small Volt dot.
    • Deleting a capture in the strip does not delete its hidden original.
    • Save as new creates a file with no original of its own, because the plain capture is still there.

    Blur is permanent in the saved file#

    A blur turns the area into flat blocks in the file you save. The pixels it hid are gone from that file. But the original, which is the picture before any edit, still holds them, and it stays in .a9snap until you Revert or delete it.

    Before you share a whole screenshots folder, delete the .a9snap folder inside it. Sharing a single file is safe, because the original is not inside that file.
