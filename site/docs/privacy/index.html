    Privacy

    The app sends nothing beyond the update check and, only if you use Pro, its license check. No account, no telemetry in the app, no uploads. The website counts visits without cookies.

    Last updated for A9 Snap 0.9.0

    A9 Snap is built to stay on your computer. This page lists everything it stores and everything it sends.

    What leaves your PC#

    Two things, and Free needs only the first. The update check, which the Microsoft Store version of A9 Snap does not even make: the Store updates it. See The update check. And, if you buy or enter a key for A9 Snap Pro, the license check. See The license check. A9 Snap has no account, no sign-in, no analytics and no crash reporting. It never uploads a screenshot anywhere.

    The update check#

    On launch and every few hours, A9 Snap asks one public file whether a newer version exists. The file is channels/dev.json or channels/stable.json, depending on your channel, at raw.githubusercontent.com in the A9 Snap releases repository on GitHub. If there is a newer version, A9 Snap downloads the installer from that same repository's releases and checks its signature before it will install anything.

    Those requests carry the normal information any web request does, such as your IP address. They carry no screenshot, no file name and no setting.

    The license check#

    Free never makes a license check. Pro does, and only after you press Get Pro, Enter key or Restore purchase, or once a key is on your PC: then A9 Snap asks the license server at a9voice.com whether the key is still good, when it starts and once a day, never in the middle of a capture.

    What a check sends:

    • the product name (a9snap-pro);
    • your license key, once you have one;
    • an identifier for this PC, which is a one-way hash of the Windows machine ID. The machine ID itself is never sent;
    • a label for this PC, such as PC 1a2b3c4d, made from that hash. It is never your computer's name;
    • for Get Pro, the same identifier, so the payment can be matched to this PC. Stripe takes your card details and email on its own page; A9 Snap never sees them.

    Those requests carry the normal information any web request does, such as your IP address. They carry no screenshot, no file name, no window title and no setting. The server stores your email and the payment from the purchase, and the PCs a key is on.

    If your PC is offline, Pro keeps working for 30 days from the last good answer. A refunded key stops working at the next check.

    What is stored on your PC#

    • Screenshots go to the clipboard and to your screenshots folder, and nowhere else. Thumbnails for the strip and the Home window are made in memory and never written to disk.
    • OCR uses Windows' built-in recognizer on your PC. The picture goes to it in memory only, and the recognized text goes only to the clipboard when you ask for it. An OCR capture saves no PNG. There are no temporary image or text files and no recognized text in the log.
    • Originals of edited captures are kept in a hidden .a9snap folder inside your screenshots folder. After a blur, the saved file has the pixels destroyed but the original still holds them. See Blur is permanent in the saved file. Delete .a9snap before you share the whole folder. Edit originals in Saving shows how many there are and clears them (to the Recycle Bin). Two small files of names and numbers sit beside them: floor.json (the highest number you deleted, so the next capture doesn't reuse it) and edited.json (which captures were edited, so the Volt dot stays after the originals are cleared).
    • Which app each capture came from is noted in .a9snap\captures.json, in the same hidden folder next to the originals. For each new capture it holds the file name, size and time, the app's name (such as Google Chrome) and the window's title, so the strip can search by them. Window titles can contain an email subject or a document's name. The notes stay in your screenshots folder, never leave this PC and never go into the log. Turn them off with Remember which app each capture came from in Saving, and press Clear there to delete what is already noted. Delete .a9snap before you share the whole folder. A secure capture never notes them.
    • Auto-redact (Pro) reads a picture with Windows' built-in recognizer on your PC, in memory, to find email addresses, phone numbers and card numbers, and blurs them. What it finds is never written to the log (the log says only how many items were blurred and how long it took), is never sent anywhere and is not kept: the blurred areas are pixels in the picture. With Redact every capture before it's copied on, the untouched original of each capture is kept in .a9snap like an edit's, and it still holds what was blurred: Clear on Edit originals in Saving removes them, and you should delete .a9snap before you share the whole folder. See Auto-redact.
    • The words in your captures (Pro, Search inside screenshots) are kept in .a9snap\text.json, in the same hidden folder next to the originals and captures.json. A9 Snap reads each capture with Windows' built-in recognizer on your PC, in memory, and the index holds the file name, size and time of each capture and the text found in it, so the strip can search by it. The index holds text from your screenshots, including anything on them that you would not want shared. It stays in your screenshots folder, never leaves this PC and never goes into the log (the log says only how many pictures were read and how long it took). Press Clear text index in Saving to delete it, or turn Search inside screenshots off, which stops reading and deletes it. Delete .a9snap before you share the whole folder. A secure capture is never read or indexed. Without Pro nothing is read.
    • Secure captures (Pro, press S in the picker) go to the clipboard and, unless you chose Clipboard only, to a folder of their own, %LOCALAPPDATA%\A9 Snap\Secure by default (on the Microsoft Store version Windows keeps that folder inside the app's own AppData; Open in the settings shows the real one). The folder is hidden and marked not to be content-indexed, so Windows Search and Explorer's thumbnail cache leave it alone. The copy on the clipboard carries the formats that keep it out of Windows' clipboard history and the cloud clipboard. A secure capture is never in the strip, the Home window, search, captures.json, the text index or your screenshots folder's numbering, notes no app or window, and never opens the editor. The log says only "secure capture saved", with the size and timing, never a file name. Clear the secure folder deletes for good, not to the Recycle Bin, and Clear the clipboard after empties the clipboard only while it still holds the secure picture. A secure capture is not encrypted. If you point the secure folder at a OneDrive, Dropbox or other synced folder, that service uploads what is in it; the settings warn you.
    • Settings are in settings.json in %APPDATA%\ai.atlas9.a9snap. A Pro key, if you have one, is kept beside it in pro-license.json.
    • The log is in the logs folder beside it. It records sizes, timings and status codes, never the content of a screenshot, a file or recognized text.
    • Start at login adds one startup entry for your Windows user, and a one-time Task Scheduler task when Windows ends your session. See Start at login.

    This website#

    The app and this website are separate. The app sends nothing beyond the update check and, for Pro, the license check above. Nothing on this page changes that.

    The website counts how it is used, without cookies and without anything that identifies you:

    • Visits and where they came from. When you open a page, the site's own script remembers, for that browser tab only, the campaign tags on the link you followed (such as utm_source), the address of the site that sent you (the host name only, never the full address) and the first page you landed on. It sends that to the license server at a9voice.com once per visit, so the count says, for example, "12 visits from a link tagged newsletter". It stores nothing on your PC beyond that tab's memory, which goes away when you close the tab, and it sets no cookie.
    • Download clicks. The Download the installer link goes through the same server, which counts the click with the same tags and then sends you on to the installer. A click on the Microsoft Store badge is counted the same way, and the badge's link carries a campaign name (such as newsletter, or direct) so the Store can tell its own installs apart.
    • A cookieless page count. The site also uses Cloudflare Web Analytics, which counts page views without cookies.

    None of these counts stores your IP address, and none can tell you apart from anyone else who came the same way. They carry no screenshot, no setting and nothing from the app. The manual's fonts and scripts come from a9snap.com. The home page loads its fonts from Google Fonts and reads the newest version number from the same GitHub file that the app uses.
