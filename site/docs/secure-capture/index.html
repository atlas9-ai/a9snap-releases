    Secure capture

    A secure capture goes to the clipboard and a folder of its own, and nowhere else. It stays out of the strip, the Home window, Windows' clipboard history and Windows Search. It is a Pro feature.

    Last updated for A9 Snap 0.7.1

    Some pictures should not end up in your screenshots folder, the strip, Windows' clipboard history or a folder that syncs to the cloud: a password, a bank page, a private message. Secure capture is for those. It is part of A9 Snap Pro: see Pro features.

    Take a secure capture#

    There are three ways to start one, and they all end in the same picker.

    From the keyboard.

    1. Press Alt+Z.
    2. Tap S. A padlock appears on the outline, and the size says Secure, for example Secure · 600 × 400.
    3. Click a window, press F for the whole screen, or drag a region, as you always do.

    From the sidebar. With Pro on, the Home window has a Secure capture button under Capture, with Alt+Z, S on it. It opens the picker with secure already on, so skip step 2.

    From the tray. With Pro on, the tray menu has Secure capture under Capture region. It does the same.

    If you changed the capture hotkey, the keys follow it: your hotkey, then S. The Shortcuts page lists them too, and the picker's hint line says S secure. The first time Pro turns on, the hint comes back for your next 5 captures.

    Tap S again to turn it off. It is never sticky: the next capture starts as a normal one.

    The toast says Secure · copied (or Secure · copied · saved) with a padlock. It shows no thumbnail and no Edit button, and clicking it does nothing, so it cannot lead to the strip.

    Without Pro there is no Secure capture button in the sidebar and no item in the tray, and S does not switch secure on. The picker says Secure capture is part of A9 Snap Pro, and the capture is a normal one. When the picker closes, the Pro sheet opens once, then stays out of your way until the next time you start A9 Snap.

    Where it goes#

    • The clipboard, with the formats that keep it out of Windows' clipboard history (Win+V) and the cloud clipboard. With Also copy as file on and a file saved, the file's path rides along too.
    • The secure folder, unless you chose Clipboard only. The default is %LOCALAPPDATA%\A9 Snap\Secure, which is not synced. Files are numbered inside that folder only, with the same prefix and digits as your screenshots, so your screenshots folder's numbering and Next file never move.

    The secure folder is hidden and marked as not to be content-indexed, so Windows Search and Explorer's thumbnail cache leave it alone. Use Open in the settings below to see it.

    What a secure capture never does#

    • It never appears in the strip, in the Home window's recent captures, in search or in the app chips.
    • It never notes which app or window it came from.
    • It never opens the editor, even with Open the editor after every capture on. Editing a secure capture is not possible, because the editor keeps originals in the screenshots folder.
    • The log says "secure capture saved" and the size and timing, and never a file name.

    Settings#

    Open Saving in the Home window and find Secure screenshots (its ? opens this page). Without Pro the card, and the Secure capture row on the Shortcuts page, show a Pro badge, and clicking either opens the Pro sheet.

    • Where secure captures go. Secure folder (the default) or Clipboard only, which writes no file anywhere.
    • Secure folder. Browse… chooses another folder, but not your screenshots folder. A folder under OneDrive, Dropbox or another synced folder shows This folder is synced to the cloud; secure captures would be uploaded, because they would be. Open shows the folder in Explorer, and on the Microsoft Store version it shows the real folder, even though Windows keeps that version's AppData in its own place. Empty now asks first, in the window.
    • Clear the secure folder. Never, When A9 Snap quits, After 1 hour, After 24 hours or After 7 days. A picture that came due while A9 Snap was closed is cleared the next time it starts. Secure pictures are deleted for good, not to the Recycle Bin. This is the one place A9 Snap deletes without a way back, because a Recycle Bin copy would defeat the point. It only clears a folder it made itself, and only .png files directly in it: choose a folder that already holds other files and A9 Snap uses it but never clears it.
    • Clear the clipboard after. Off (the default), 30 seconds, 1 minute or 5 minutes. A9 Snap clears the clipboard only if it still holds the secure picture. Anything you copied since is never cleared.

    What it does not do#

    A secure capture is not encrypted, and it is not locked away: anyone who can open your Windows account can open the secure folder. It keeps a picture out of the places that would otherwise keep it, and it can delete it for you on a schedule. See Privacy.
