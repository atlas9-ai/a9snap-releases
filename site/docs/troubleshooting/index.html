    If something goes wrong

    Fixes for the problems people hit most: a hotkey that does nothing, a picture that won't paste, a missing tray icon, and an update that fails.

    Last updated for A9 Snap 0.3.6

    Find your problem below. If none of it helps, the log file says what A9 Snap did.

    A hotkey is taken by another app#

    What you see: pressing Alt+Z does nothing, the tray icon wears a warning badge, and Settings says Alt+Z is taken by another app. Pick another.

    Another program already owns that key, and Windows lets only one program have it.

    1. Open the Home window and choose Shortcuts.
    2. Click the box that is marked, then press a different combination, such as Ctrl+Alt+P.

    The same goes for OCR capture hotkey and Recent captures hotkey. If you would rather keep the key, close or reconfigure the other app first, then restart A9 Snap.

    Nothing is on the clipboard, or it won't paste#

    • Read the note. Copied · snag_0042.png means the picture is on the clipboard. Saved snag_0042.png · not copied gives the reason it was not. These notes show for five seconds, even with confirmations off.
    • Try another app. Paste into Paint or a document. If it works there, the first app wants a file instead of a picture: turn on Also copy as file in Saving.
    • Check a clipboard tool. A clipboard manager or a remote desktop session can hold the clipboard for a moment. Try again.
    • Use the strip. Press Alt+Shift+Z, pick the capture and press Enter to copy it again as a picture plus its file.

    OCR finds no text or cannot start#

    • No text found means Windows could not read words in the selected picture. Try a tighter region around clear, upright text, or a larger region with less background. Your previous clipboard contents are unchanged.
    • If the note says Windows OCR is unavailable for your profile's languages, install an OCR-capable language in Windows Settings under Time & language → Language & region, then try again.
    • OCR is local. A9 Snap does not send the picture to an online service, so this does not require an account or an API key.

    The picture wasn't saved#

    The note says Copied · not saved with a reason, for example that the folder can't be written to or the disk is full. The picture is still on your clipboard, so paste it now. Then pick a folder you can write to in Saving.

    The next number is wrong#

    The number is the highest file in the folder plus one, counting only files named like your prefix. If you moved or deleted files, it follows the folder. See File names and numbering.

    A9 Snap did not start after a restart#

    1. Open the Home window (from the Start menu, if the tray icon is missing) and choose Shortcuts.
    2. Check that Start at login is on.
    3. If a line says Windows has turned this off in Startup apps., click Fix in Windows and turn A9 Snap on there.

    If Windows closed your apps for an update and the restart never finished, A9 Snap starts again by itself two minutes later. See Start at login.

    I can't find the tray icon#

    Click the ^ arrow by the clock to show hidden icons. You can drag the Bullseye out onto the taskbar to keep it visible. If it isn't there, start A9 Snap from the Start menu.

    Windows says it protected your PC#

    Early builds are not signed with a Windows certificate yet. Click More info, then Run anyway. The Microsoft Store version avoids this step. See Getting started.

    An update failed#

    The Home window's version line says Check failed, and the line under Version in Updates and about says why. Couldn't reach the update server. means your network, a firewall or a proxy blocked the check. The update didn't pass its signature check, so it was not installed. means the download was damaged or changed on the way, and A9 Snap refused it.

    1. Open Updates and about and click Check for updates again. A9 Snap checks on launch and every few hours, so a short outage fixes itself.
    2. Make sure your network or firewall allows raw.githubusercontent.com and github.com. See Privacy.
    3. If it still fails, download the installer again from a9snap.com and run it. It updates your copy and keeps your settings.

    Where the log file is#

    A9 Snap writes a log to a9snap.log in this folder:

    %APPDATA%\ai.atlas9.a9snap\logs

    Press Win+R, paste that folder path and press Enter to open it. The log records starts and exits, hotkey conflicts, update checks, sizes, timings and the reasons for errors. It never contains the content of your screenshots. Your settings are in settings.json in the folder above it.

    If you installed A9 Snap from the Microsoft Store, Windows keeps those files inside the app's own folder instead. Press Win+R, type %LOCALAPPDATA%\Packages and press Enter, open the folder that starts with Atlas9LLC.A9Snap_, then LocalCache\Roaming\ai.atlas9.a9snap\logs. Your screenshots are not there: they stay in your screenshots folder, whichever way you installed A9 Snap.
